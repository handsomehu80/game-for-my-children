# 中国9年义务教育知识体系

## 概述

本文档描述了基于中国教育部课程标准的9年义务教育知识体系L3结构，用于「波吉王子海洋探险」儿童教育游戏的学习追踪系统。

## 体系结构

- **L1**: 科目 (Subject)
- **L2**: 领域 (Domain)
- **L3**: 专题 (Topic)
- **L4**: 具体知识点 (Knowledge Point)

## 覆盖科目

| 科目 | 适用年级 | 说明 |
|------|----------|------|
| 语文 | 1-9年级 | 汉语语言文字学习 |
| 数学 | 1-9年级 | 数理逻辑思维 |
| 英语 | 3-9年级 | 英语语言学习 |
| 科学 | 3-6年级 | 小学科学启蒙 |
| 物理 | 8-9年级 | 初中物理 |
| 化学 | 9年级 | 初中化学 |
| 历史 | 7-9年级 | 中国与世界历史 |
